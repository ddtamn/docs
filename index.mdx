## How it works

Svelte Audio UI follows the same philosophy as shadcn/ui and shadcn-svelte: you don't install it as a runtime dependency. You use the CLI to copy components into your project and own them completely.

<Steps>
  <Step title="Initialize shadcn-svelte">
    Make sure you have a Svelte 5 project with Tailwind CSS v4 and shadcn-svelte initialized.
  </Step>
  <Step title="Add a component">
    Use the shadcn-svelte CLI to copy any component into your project:
    ```bash
    pnpm dlx shadcn-svelte@latest add https://svelte-audio-ui.vercel.app/r/player.json
    ```
  </Step>
  <Step title="Wrap your app with AudioProvider">
    Mount `AudioProvider` at your layout root to initialize the audio engine:
    ```svelte
    <AudioProvider tracks={initialTracks}>
      {@render children()}
    </AudioProvider>
    ```
  </Step>
  <Step title="Use the components">
    Drop `AudioPlayer` components anywhere in your UI — they read from the shared store automatically.
  </Step>
</Steps>
